Этот файл описывает особенности NetHack, собранного для Windows.

Новым игрокам обязательно следует прочитать GuideBook.txt, который
содержит основную информацию об игре в NetHack. Его можно найти в той же
папке, что и исполняемый файл NetHack.

Порт NetHack для Windows поддерживает некоторые дополнительные или
расширенные команды, а также некоторые параметры конфигурационного файла
NetHack.

Активный конфигурационный файл NetHack хранится в подпапке nethack
внутри папки User Profile пользователя. На конфигурационный файл можно
ссылаться в устаревшей командной строке CMD так:
    %USERPROFILE%\nethack\.nethackrc

В powershell на конфигурационный файл пользователя можно ссылаться так:
    $env:USERPROFILE\nethack\.nethackrc

Некоторые параметры применимы только к «Graphical Interface».
Они обсуждаются отдельно в своей секции.

1. Сочетания с клавишей ALT
----------------------------------------------
Нетрафический (tty) интерфейс всегда работает в «режиме NetHack»,
а «NetHack for Windows - Graphical Interface» позволяет переключать
режим. В не-NetHack режиме все сочетания с клавишей ALT отправляются
самой Windows, а не в NetHack.

Во время игры в режиме NetHack вы можете нажать клавишу ALT в
сочетании с другой клавишей, чтобы выполнить расширенную команду
как альтернативу нажатию последовательности с клавишей #.
Доступны следующие команды:

    Alt-2    #twoweapon      - переключить бой двумя оружиями (недоступно
                               в режиме number_pad)
    Alt-a    #adjust         - настроить буквы инвентаря.
    Alt-c    #chat           - поговорить с кем-нибудь или чем-нибудь.
    Alt-d    #dip            - окунуть предмет во что-нибудь.
    Alt-e    #enhance        - улучшить свой навык владения оружием.
    Alt-f    #force          - взломать замок.
    Alt-i    #invoke         - вызвать силы предмета.
    Alt-j    #jump           - прыгнуть в место.
    Alt-l    #loot           - обыскать сундук на полу.
    Alt-m    #monster        - использовать особую способность монстра.
    Alt-n    #name           - дать имя предмету или типу предметов.
    Alt-o    #offer          - принести жертву богам.
    Alt-p    #pray           - молиться богам о помощи.
    Alt-q    #quit           - выйти из игры. (То же, что #quit)
    Alt-r    #rub            - потереть лампу.
    Alt-s    #sit            - сесть.
    Alt-t    #turn           - обратить в бегство нежить.
    Alt-u    #untrap         - обезвредить что-нибудь.
    Alt-v    #version        - перечислить параметры компиляции этой
                               версии NetHack.
    Alt-w    #wipe           - вытереть лицо.
    Alt-?    #?              - показать список расширенных команд

2. Параметры, которым вы задаёте значение (только Graphical Interface)
----------------------------------------------------------------

«NetHack for Windows - Graphical Interface» распознаёт следующие
дополнительные параметры, которые нетрафическая (tty) версия будет
молча игнорировать. Это параметры, задающие атрибуты различных
окон. Настраиваемые окна включают окна меню (например, список
инвентаря), текстовые окна (например, экраны «Это написано в книге
...»), окно сообщений (где показываются события игры), окно состояния
(где отображаются имя персонажа и его характеристики) и окно карты
(где рисуется карта).

Параметры выравнивания окон:

    align_message  Задаёт, с какой стороны экрана NetHack выравнивается
                   окно сообщений. Этим параметром можно выровнять
                   окно по «top» или «bottom».
                   По умолчанию: [TOP]

    align_status   Задаёт, с какой стороны экрана NetHack выравнивается
                   окно состояния. Этим параметром можно выровнять
                   окно по «top» или «bottom».
                   По умолчанию: [BOTTOM]

Параметры окна карты:

    map_mode       Задаёт, какой режим карты использовать.
                   Доступны следующие режимы карты:
                   tiles (показывать объекты на карте цветными тайлами),
                   ascii4x6, ascii6x8, ascii8x8, ascii16x8, ascii7x12,
                   ascii8x12, ascii16x12, ascii12x16, ascii10x18
                   (используют шрифт такого размера для отображения
                   объектов на карте) или fit_to_screen (режим ascii,
                   который вписывает всё в один экран).
                   По умолчанию: [tiles]

    scroll_margin  Задаёт число клеток карты от края окна карты,
                   после которого происходит прокрутка.
                   По умолчанию: [5]

    tile_file      Альтернативный файл с растровым изображением для
                   тайлов. Это должен быть файл .bmp, организованный
                   как 40 прямоугольных тайлов в ширину. Описание
                   точного содержимого каждого тайла в .bmp выходит
                   за рамки этого документа; оно должно соответствовать
                   спискам объектов, использованным при сборке NetHack.

    tile_height    Используется вместе с tile_file для задания высоты
                   каждого тайла в пикселях. Этот параметр можно задать
                   только в конфигурационном файле defaults.nh.
                   По умолчанию: [16]

    tile_width     Используется вместе с tile_file для задания ширины
                   каждого тайла в пикселях. Этот параметр можно задать
                   только в конфигурационном файле defaults.nh.
                   По умолчанию: [16]

Другие параметры окон:

    windowcolors   Задаёт цвета для различных окон.
                   Этот параметр можно задать только в
                   конфигурационном файле defaults.nh, и он имеет
                   следующий формат:
                       window-type foreground/background
                   Примечания:
                      - Требуются оба цвета — переднего плана и фона,
                        и они должны быть разделены косой чертой.
                      - «window-type» — это либо «message», либо «status»
                        (Краткие формы: «msg» или «sts»).
                      - «foreground» и «background» можно задать как
                        имя цвета (например, «blue») или как
                        шестизначное шестнадцатеричное значение RGB
                        (например, «#8F8F8F»)
                      - Доступны следующие имена цветов:
                        black, red, green, brown, blue, magenta,
                        cyan, gray (или grey), orange, brightgreen,
                        yellow, brightblue, brightmagenta, brightcyan,
                        white, trueblack, purple, silver, maroon, fuchsia,
                        lime, olive, navy, teal, aqua. Кроме того, можно
                        использовать следующие имена для ссылки на
                        настройки Windows по умолчанию: activeborder,
                        activecaption, appworkspace, background, btnface,
                        btnshadow, btntext, captiontext, graytext, highlight,
                        highlighttext, inactiveborder, inactivecaption,
                        menu, menutext, scrollbar, window, windowframe,
                        windowtext.

                        Пример:
                        OPTIONS=windowcolors:sts #00FF80/blue msg menutext/menu

    font_menu      Задаёт имя шрифта меню.
    font_message   Задаёт имя шрифта сообщений.
    font_status    Задаёт имя шрифта состояния.
    font_text      Задаёт имя шрифта текста.

    font_size_menu Задаёт размер шрифта меню.

    font_size_message
                   Задаёт размер шрифта сообщений.

    font_size_status
                   Задаёт размер шрифта состояния.

    font_size_text Задаёт размер шрифта текста.

Прочие параметры:

    vary_msgcount  Число строк, отображаемых в окне сообщений.


3. NetHack for Windows - Graphical Interface, дополнительные и расширенные команды
-------------------------------------------------------------------------

Следующие функциональные клавиши активны в
«NetHack for Windows - Graphical Interface»:

    F4             Включить или выключить режим обзора уровня
                   Эта клавиша переключает карту между видом, который
                   вписан точно в окно, и видом, который показывает
                   различные символы в их обычном размере. Это полезно,
                   чтобы получить представление о том, где вы находитесь
                   на уровне.

    F5             Включить или выключить тайловое отображение.
                   Эта клавиша переключает между тайловым и
                   традиционным ASCII-отображением. Это эквивалентно
                   использованию параметра «map_mode».

    F10            Активировать строку меню.
                   Эта клавиша активирует строку меню, позволяя вам
                   выбирать между меню: File, Map, Window Settings
                   и Help.

4. Меню графического порта
-----------------------

File
  Save - Позволяет сохранить и выйти из игры
  Quit - Позволяет выйти из игры

Map - Обеспечивает выбор режима карты. Эквивалентно использованию
параметра map_mode.

Window Settings - Изменяет настройки NetHack текущего вошедшего
пользователя. Доступна только одна настройка: NetHack mode, которую
можно включить или выключить. Режим NetHack позволяет использовать
клавишу ALT для игровых команд [см. список выше]. Вы можете
использовать F10 для доступа к строке меню в режиме NetHack.
Вы также можете очистить настройки NetHack текущего вошедшего
пользователя. Настройки в этом окне сохраняются в реестре текущего
вошедшего пользователя.

Help - Обеспечивает справку по различным частям NetHack.


5. Цифровая клавиатура (для режима «OPTION=number_pad»)
------------------------------------------------

Цифровая клавиатура и окружающие её клавиши действуют как макросы для
различных команд в NetHack.  Для максимального использования этих
клавиш Num Lock должен быть включён:

          Клавиша      Обычно        С Shift
       ----------   ----------    -------------
       1, 2, 3, 4   Движение      Бег
       6, 7, 8, 9   в направлении в направлении

        0 (Ins)     Инвентарь     Инвентарь
                                  по категориям

        . (Del)     Ждать ход     : - Осмотреться

        +           Список        P - Надеть
                    заклинаний    аксессуар

        -           m - Только    Предыдущее
                    движение      сообщение

    NetHack for Windows - особенности tty-интерфейса:
    ------------------------------------------------------

      В нетрафическом (tty) интерфейсе, когда вы используете клавишу Ctrl
      с клавишей направления (1, 2, 3, 4, 6, 7, 8, 9), это означает «идти
      в указанном направлении, пока не упрёшься в стену или не наткнёшься
      на что-нибудь интересное».

    NetHack for Windows - особенности Graphical Interface:
    ------------------------------------------------------------

      Можно прокручивать или панорамировать карту в определённом
      направлении:

        Ctrl-Shift-Left  (4)     Прокрутить карту влево
        Ctrl-Shift-Right (6)     Прокрутить карту вправо
        Ctrl-Shift-Up    (8)     Прокрутить карту вверх
        Ctrl-Shift-Down  (2)     Прокрутить карту вниз
        Ctrl-Shift-Home  (7)     Прокрутить карту влево до левого края
        Ctrl-Shift-End   (1)     Прокрутить карту влево до правого края
        Ctrl-Shift-PgUp  (9)     Прокрутить карту влево до верхнего края
        Ctrl-Shift-PgDn  (3)     Прокрутить карту влево до нижнего края
